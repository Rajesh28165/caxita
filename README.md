# Caxita Flutter Flight Assignment

Flutter application developed as part of the Caxita Tech Solutions
Flutter Developer machine test.

## Features

- Fetch flight data from REST API
- Store flight data locally using SQLite
- Display flight information
- Airline filtering
- Flight sorting
- Loading and error states
- Clean Architecture
- Bloc/Cubit state management

## Tech Stack

- Flutter
- Dart
- Bloc/Cubit
- REST API
- SQLite
- Clean Architecture
